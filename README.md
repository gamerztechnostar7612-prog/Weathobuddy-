# 🌤️ SkyCast Weather

A responsive weather web app showing:

- Current temperature and feels-like temperature
- Weather condition
- Humidity
- Wind speed and direction
- Air Quality Index (US AQI)
- Visibility
- Atmospheric pressure
- UV index
- Rain probability
- 12-hour forecast
- 7-day forecast
- City search
- Browser geolocation

## 🚀 Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## 🌐 Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide your live website URL.

## 📡 Data

This project uses the free, no-API-key services from Open-Meteo:

- Weather forecast API
- Geocoding API
- Air Quality API

See https://open-meteo.com/ for API documentation and licensing details.
